# Estudo de ESP32 a partir da colmeia inteligente

**Situação em outubro de 2026:** Material de autoformação concluído e disponível para estudo individual.

Organizamos um material de autoformação sobre programação do ESP32, sensores, armazenamento, envio de dados e funcionamento da colmeia. Incluímos explicações, exercícios, simulações e preparação para apresentação do projeto.

## Como consultar

Baixe a pasta [material-interativo](material-interativo/) inteira e abra index.html no navegador. Para usar um servidor local, execute python3 serve.py --directory . dentro dessa pasta. As instruções acompanham o material. O firmware é uma cópia pedagógica com configurações de acesso substituídas.
